🏘️ Residenciales Valle del Ángel - Sistema de Gestión Inmobiliaria
Este proyecto nace como una solución tecnológica integral para la residencial Valle del Ángel. Actualmente, la comunidad enfrenta retos en la automatización de accesos y la comunicación interna, careciendo de sistemas digitales para el registro de visitas, gestión de pagos y difusión de información oficial.

🚀 Nuestra Propuesta
Brindamos una plataforma robusta que optimiza la interacción entre la administración y los residentes, mejorando la seguridad y la convivencia a través de:
  - Control de Acceso Inteligente: Generación y validación de ingresos mediante códigos QR.
  - Gestión Administrativa: Registro centralizado de propietarios, servicios y catálogo de mantenimientos.
  - Control Financiero: Módulo de ingresos y seguimiento de pagos de servicios.
  - Comunicación Interna: Panel de comunicados oficiales para la comunidad.

🛠️ Stack Tecnológico
El ecosistema de la aplicación fue desarrollado utilizando las siguientes tecnologías:
  - Frontend: Angular (TypeScript) con una interfaz moderna y responsiva.
  - Backend: Node.js y Express para una API REST eficiente.
  - Base de Datos: MySQL para la persistencia de datos relacionales.
  - Seguridad y Utilidades: Implementación de variables de entorno (dotenv), generación de IDs únicos (uuid) y validaciones de acceso.

🔧 Configuración del Proyecto
Requisitos previos
  - Node.js instalado.
  - Servidor MySQL activo.
Instalación
  1. Clona el repositorio: git clone https://github.com/universidad-usap/residencialesGrupo2.git
  2. Configura el backend:
     cd backend
     npm install
     * Crea tu archivo .env con las credenciales de tu DB
     npm run dev
  3. Configura el frontend:
     cd ../frontend
     npm install
     ng serve
